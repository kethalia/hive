## Minimum GitHub access and observed gaps

Use separate setup and runtime credentials scoped to this repository. Setup requires the provider permissions for the actual bounded setup: repository **Administration: write** for creating the protected environments and, if selected, pilot-only classic branch protection; **Environments: write** for environment variables and secrets; **Variables: write** and **Secrets: write** only if repository-level values are required. Workflow files require **Contents: write** and, for a GitHub App/fine-grained token modifying workflows, the appropriate **Workflows: write** permission. A reviewer is a separate authorized GitHub identity, not a token scope. The source-publishing identity needs repository **Contents: write** to publish its scoped refs and **Pull requests: write** to open its PR. The runtime release identity should have only the permissions its operations need: repository **Contents: write** for merge, **Pull requests: read**, **Actions: read**, **Checks: read**, **Administration: read** for classic protection and ruleset details, plus metadata access; confirm exact producer and reviewer permissions through a non-mutating check. Do not install the setup administrator credential in the release Worker.

The current `gh` integration successfully read repository, collaborator, environment list, Actions runs and rules metadata, but these reads returned `403 Resource not accessible by integration`:

- `GET /repos/kethalia/hive/actions/variables`: `X-Accepted-Github-Permissions: actions_variables=read`.
- `GET /repos/kethalia/hive/actions/secrets`: `X-Accepted-Github-Permissions: secrets=read`.
- `GET /repos/kethalia/hive/environments/copilot/variables` and `/secrets`: `X-Accepted-Github-Permissions: environments=read`.

These results show missing read capabilities for that integration; they do not establish whether another separately authorized credential is available. Do not print or copy token values into this record. GitHub's documentation specifies [environment administration](https://docs.github.com/en/rest/deployments/environments), [Actions variables](https://docs.github.com/en/rest/actions/variables), and [Actions secrets](https://docs.github.com/en/rest/actions/secrets) permissions. Standard hosted runners on public repositories are free, but artifact storage shares the account allowance; confirm storage headroom before the one-day upload artifact and stop rather than adding costs. See [GitHub Actions billing](https://docs.github.com/en/billing/concepts/product-billing/github-actions) and [workflow event triggering](https://docs.github.com/en/actions/how-tos/write-workflows/choose-when-workflows-run/trigger-a-workflow).
