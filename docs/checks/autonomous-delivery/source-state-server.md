# Fresh accepted-source state (disabled)

`POST /api/delivery/source-publication/state` returns factual immutable accepted-source and current-head data under fresh host and independent producer authentication. It does not depend on the original publication grant, its nonce or R2 availability. No default flag, production migration, public preview-path exception or native/controller composition enables it.

The exact strict request/response schemas and signature helper are in `src/lib/delivery/source-state-contracts.ts`. The request action is `read_source_state`, with fresh issuedAt/expiresAt (at most60seconds), requestId, registration/server/manager-thread, immutable checkoutBinding, taskId, operationId and optional exact revisionId. The proof domain is `hive-source-transport-v1`, POST, the fixed state path and canonical unsigned JSON, separated by newlines. Browser origins, query selectors, compression, excess bodies and stalled reads/cancellation are rejected.

The service locks current registration → persisted finalized guardian runtime/admission/metadata → intent/binding → task. It derives owner from registration, verifies project/task/physical scope, resolves the exact accepted operation and producing attempt/output relationship, validates the current source chain, and reads no model-supplied producer/status. Optional revisionId must match the accepted operation exactly. It performs no application data writes, grant consumption, artifact upload, lease renewal or scheduling.

Response scope echoes owner, request, registration/server/thread, manager binding/digest, immutable physical checkout and task. Admission carries the exact runtime/admission generations, producer digest, checkout incarnation and barrier generation. Metadata includes checkout/Git inode pins, policy/namespace receipt digests and `pinsDigest` (the store's metadataPinsDigest over the full stored metadata evidence; it is not a standalone hash of pins).

`accepted` contains the immutable operation/revision, predecessor and parent SHA, tree/manifest digests, provider/ref/PR identities, producing attempt/step and retained proof digest. `current` separately identifies the task's current source/head/version, physical base and branch. `isCurrent:false` preserves historical data without authorizing rollback. Every response has `publicationAuthorized:false` and `executionAuthorized:false`. Freshness is bounded by30seconds, the signed request expiry, registration expiry and guardian authority expiry.

Local metadata apply still requires independently authorized project input exclusion, matching registered metadata-producer identity and inode pins, exact predecessor/version CAS against the local accepted-source journal, preservation of dirty files, and a final current-source comparison before native admission. This factual readback supplies none of those permissions itself.

`source-state-local/full-expiry.txt` records six actual local PostgreSQL cases, including a real61-second wait, same-registration heartbeat renewals and a fresh read after the original59-second publication wire expired. Normal CI skips only that slow optional case. Tests also cover foreign owner/task/operation/revision/writer scope, immutable historical output after a second source advance, producer revocation, actual closed barrier remaining denied after flags turn off, retained physical writer and unchanged logical data across reads. Source acceptance, native facts, package/owner authorization and provider data are explicit local fixtures; no real provider/installed bootstrap proof is claimed. Five route tests cover default flags, missing R2/policy independence, bounded parsing and sanitized failures.
