# tmux session lifetime

Hive uses tmux to keep terminal processes and in-memory scrollback alive across
browser disconnects. The terminal proxy attaches to an existing named session,
and the Coder tmux app uses the same attach-or-create behavior on its default
socket. The F12 menu and 50,000-line live history remain available.

Hive no longer installs or runs tmux-resurrect, tmux-continuum, or their plugin
manager. It does not periodically save pane contents, save layouts, restore old
terminal output, or relaunch saved commands. Stopping the workspace/container or
tmux server ends those processes; reconnecting afterwards creates fresh sessions.

## Existing workspaces

Roll out both the updated templates and the new workspace image digests, then
restart affected workspaces during a suitable maintenance window. Existing tmux
servers keep their loaded configuration until they exit. This change does not
restart running servers automatically.

The blocking startup script recognizes only the exact default `.tmux.conf`
generated by the retired `anomaly/tmux` 1.0.4 module, allowing for its configured
save interval. It renames that file to a private
`.tmux.conf.hive-retired-<id>` backup. It does not overwrite personal configuration
or follow symlinks/hardlinks. Custom configurations that enable those plugins are
preserved and need an explicit review by their owner.

Existing snapshots in `~/.tmux/resurrect` and old home-directory plugin files are
preserved. Removing old saved data is a separate cleanup decision.
