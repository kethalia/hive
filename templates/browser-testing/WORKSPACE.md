# Browser testing workspace

Use this workspace for Chrome automation, Playwright tests, screenshots, traces, accessibility
inspection, and headed browser debugging. Keep product implementation in the owning software or
specialist workspace and bring only the repository or endpoint needed for the browser task here.

## Start here

- Use `claude` or `codex` in a terminal; both receive the Playwright MCP only in this profile.
- Open Desktop from Coder for headed Chrome inspection.
- Use `browser-screenshot <url>` and `browser-html <url>` for lightweight command-line checks.
- Store screenshots, traces, and downloads under the task repository or another explicit artifact
  directory.

## Included tools

- Google Chrome with XFCE/KasmVNC desktop access
- Playwright MCP for Claude Code and Codex
- Playwright editor support, code-server, File Browser, tmux, and common CLI tooling

Unity, Blender, KiCad, and infrastructure credentials are intentionally outside this workspace.
