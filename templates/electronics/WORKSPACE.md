# Electronics workspace

Use this workspace for KiCad schematic and PCB work, hardware documentation, simulation, and related
firmware repositories.

## Start here

- Open Desktop from Coder and launch KiCad.
- Clone or add the hardware repository under `~/projects`.
- Run repository-provided ERC/DRC and `kicad-cli` checks before producing artifacts.
- Keep generated manufacturing files separate from source designs and review them explicitly.

## Included tools

- KiCad 9 with standard symbols, footprints, templates, and 3D packages
- `kicad-cli`, C/C++ editor support, Python, and common build tools
- Claude Code, Codex, code-server, File Browser, headed Playwright, and tmux

USB/serial devices and physical bench equipment are not exposed by default.
